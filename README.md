# SQLite MCP

Queries a local SQLite database. This plugin installs and configures it in your workspaces.

Upstream server docs: https://www.npmjs.com/package/mcp-server-sqlite

Installs from the Camillia hub as `sqlite-mcp-11b368`. On every new task the plugin posts
the ready-to-paste `mcp.servers` entry and the setup steps as a task comment.
